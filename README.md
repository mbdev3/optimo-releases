# Optimo — Releases

Official downloads for **[Optimo](https://optimoapps.com)** — a desktop app that
compresses, converts, and transforms images & video **entirely on your machine.
Zero uploads.**

## Download

Get the latest build from the [**Releases**](../../releases/latest) page, or from
the website: **<https://optimoapps.com/download>**

| Platform | File |
|----------|------|
| **macOS** (Apple Silicon / Intel) | `Optimo-<version>-arm64.dmg` · `Optimo-<version>-x64.dmg` |
| **Windows** (x64) | `Optimo-Setup-<version>.exe` |
| **Linux** | `Optimo-<version>.AppImage` · `optimo_<version>_amd64.deb` |

> On first launch your OS may warn that the app is from an unidentified developer
> (the builds aren't code-signed yet). The [install help](https://optimoapps.com/download#install)
> has the one-step fix for each platform.

## About this repository

This repo hosts **only the compiled installers** (as GitHub Releases) — Optimo's
source code is maintained privately. New versions are built for macOS, Windows,
and Linux and published here automatically by CI on each tagged release.
